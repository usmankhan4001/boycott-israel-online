# BoycottIsrael — By Takweyat Foundation

> **Boycott Now to Save Your Future.**

A modern Progressive Web App (PWA) and verified directory of boycotted multinational brands and authentic Pakistani alternatives, powered by **Takweyat Foundation**.

## Features

- 🔍 **Instant Search & Real-Time Filtering**: Zero-latency search across 550+ verified FMCG brands and parent conglomerates.
- 📷 **Live 729 Barcode Camera Scanner**: Real-time camera scanner with instant Israeli `729` barcode prefix detection.
- 🛒 **Conscience Grocery Checklist**: Monthly grocery planner with % Ethical Basket calculator, 1-tap Pakistani alternative swaps, and WhatsApp export.
- 🇵🇸 **BDS & Complicity Evidence**: Detailed documented evidence of corporate ties to Israeli apartheid, illegal settlements, and military operations.
- 📱 **Installable PWA**: Works 100% offline inside supermarkets with local data persistence.

## Tech Stack

- **React 19 + TypeScript**
- **Vite 6**
- **Tailwind CSS**
- **Lucide Icons**
- **html5-qrcode**

## Development

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Build for production (Cloudflare Pages / Vercel)
npm run build
```
